Core Features

What the prototype demonstrates

Each screen mirrors the main roles and workflows from the AgroConnect project idea.

1

Farmer listing flow

Farmers can add produce, set quantity and pricing, and review active listings in a clear dashboard layout.

2

Consumer discovery flow

Consumers can search produce, compare prices, and browse location-based cards with fair-price messaging.

3

Admin moderation flow

Administrators can review users and listings using clean table-based management screens.
